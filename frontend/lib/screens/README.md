# Developer Guide



## Screen Layouts

### Login
- Contains a form for logging in, a title, and a logo
- Has buttons to navigate to registration and password recovery
- Skips to Home Screen if logged in

### Register Screen
- Has a form for registration

### Forgot Password Screen
- IDK how this can work

### Home Screen
- Displays navigation options to other screens
- Lists updates, and other relevant info
- Includes options for logging out and changing the theme (dark/light)

### Settings Screen
- Contains sections for User Profile and App Settings
- Additional features will be added as the app evolves

### About Screen
- Provides a description of the app and the developers
- Links to the GitHub repo and/or App Store
- Contains other relevant information
